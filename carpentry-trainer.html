ℹ How to fix two components together

Press and drag from a connection point, then release: over open board it drops a route point (press-drag-release again to keep going), over another connection point it fixes them together and finishes. Esc or right-click cancels. Pick a fixing type again for the next one, even the same type.

Structure Check

Every connection point expects one specific fixing type (see the coloured ring around it). A wrong-type fixing shows as a fault right at the mistake — same idea as plugging the wrong wire into the wrong terminal. There's no power switch here: the check runs live, all the time, from the Ground / Floor Datum outward.

No faults.

Level & Plumb Check

Drag the spirit level onto any placed component. It reads TRUE (bubble centred) once that component is correctly fixed all the way back to a true reference — or OUT if a fixing along the way is missing or the wrong type.
